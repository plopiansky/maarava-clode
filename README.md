# אתר ישיבת מערבא – מכון רובין

Astro + [EmDash CMS](https://github.com/emdash-cms/emdash), מותאם ל-Cloudflare Workers (D1 + R2).
כל התוכן ניתן לעריכה בפאנל הניהול, בלי לגעת בקוד.

## הרצה מקומית
```bash
npm install
npm run dev          # http://localhost:4321
```
בכניסה הראשונה פותחים את האשף: `POST /_emdash/api/setup` (או דרך `http://localhost:4321/_emdash/admin`)
וטוענים את תוכן ההתחלה מ-`seed/seed.json`.
פאנל ניהול: `/_emdash/admin` (בפיתוח אפשר להיכנס עם `/_emdash/api/setup/dev-bypass?redirect=/_emdash/admin`).

## מדריך ניהול (`/_emdash/admin`)
בתפריט הצד, תחת Content, התוכן מחולק לקבוצות:

**1. טקסטים וכותרות** – "טקסטים וכותרות": כל כותרת/פסקה באתר (שורה ריקה = פסקה חדשה, `**כך**` = מודגש). הפריט **"קישור הרשמה"** קובע לאן מובילים כל כפתורי ההרשמה (שדה "קישור"). אפשר להעלות תמונת רקע/תמונה לפריטים כמו "ראשי", "ראש הישיבה", "הסיפור שלנו", "תכנית הלימודים".

**2. כרטיסים ורשימות** – מוח/נפש/גוף, מסלולי לימוד, סדר יום, נקודות הגישה החינוכית, בוגרינו, מסלולי בגרות, הערכים שלנו. בכל אחד "סדר הצגה" (מספר קטן = ראשון).

**3. גלריית תמונות** – "הוספה" → כיתוב, תמונה (העלאה מהמחשב, אפשר להעלות הרבה דרך Media), תיאור (מופיע בהגדלה), וסימון "להציג בדף הבית" (עד 5 תמונות בדף הבית). כל התמונות מופיעות ב-`/gallery` עם הגדלה וכיתוב.

**4. צוות הישיבה** – שם, תפקיד, תמונה, וקבוצה: `management` (הנהלה) או `rabbi` (רבנים).

> חשוב: פריט חדש נשמר כטיוטה עד שלוחצים **Publish**.

## פריסה ל-Cloudflare
ה-D1 (`marava`) וה-R2 (`maarava`) כבר מוגדרים ב-`wrangler.jsonc`.

חיבור הריפו ב-Workers Builds: Build command `npm run build`, Deploy command `npx wrangler deploy`.
(או מקומית: `npm run deploy`.)

אחרי הפריסה הראשונה:
1. להגדיר משתנה `EMDASH_SITE_URL` (Settings → Variables) לכתובת האתר.
2. לפתוח `https://<האתר>/_emdash/admin`, להשלים את אשף ההתקנה (כולל "טען תוכן לדוגמה") וליצור מנהל.
