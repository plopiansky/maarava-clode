# אתר ישיבת מערבא – מכון רובין

Astro + [EmDash CMS](https://github.com/emdash-cms/emdash), מותאם ל-Cloudflare Workers (D1 + R2).
כל התוכן ניתן לעריכה בפאנל הניהול, בלי לגעת בקוד.

## הרצה מקומית
```bash
npm install
npm run dev          # http://localhost:4321
```
בכניסה הראשונה פותחים את האשף: `POST /_emdash/api/setup` (או דרך `http://localhost:4321/_emdash/admin`)
וטוענים את תוכן ההתחלה מ-`seed/seed.json`.
פאנל ניהול: `/_emdash/admin` (בפיתוח אפשר להיכנס עם `/_emdash/api/setup/dev-bypass?redirect=/_emdash/admin`).

## מדריך ניהול (`/_emdash/admin`)
בתפריט הצד, תחת Content, התוכן מסודר לפי דפי האתר:

**1. דף ראשי** – "אזורים וטקסטים": כל אזור בדף הראשי בשורה נפרדת, למשל **"ראשי – ראש הישיבה (תמונה, שם וציטוט)"** (העלאת תמונה + שינוי שם וציטוט), **"ראשי – חזון ומטרות"**, **"ראשי – כותרת עליונה"** (כולל תמונת הרקע). מתחתיו: מוח/נפש/גוף, מסלולי לימוד, סדר יום, נקודות הגישה, בוגרינו, מסלולי בגרות.

**2. דף אודות** – הסיפור שלנו (טקסט + תמונה), תכנית הלימודים, המיקום, והערכים שלנו.

**3. דף צוות** – כותרות וטקסט, ו"אנשי צוות" (שם, תפקיד, תמונה, קבוצה: `management` = הנהלה, `rabbi` = רבנים).

**4. דף גלריה** – "תמונות": כיתוב, תמונה, תיאור, וסימון "להציג בדף הבית" (עד 5). כל התמונות מופיעות ב-`/gallery` עם הגדלה.

**5. הגדרות כלליות** – קישור ההרשמה (לשם מובילים כל כפתורי "הרשמה לישיבה"), טלפון, מייל ומיקום.

בטקסט ארוך: שורה ריקה = פסקה חדשה, `**כך**` = מודגש.
> חשוב: פריט שנוצר או נערך נשמר כטיוטה עד שלוחצים **Publish**.

## פריסה ל-Cloudflare
ה-D1 (`marava`) וה-R2 (`maarava`) כבר מוגדרים ב-`wrangler.jsonc`.

חיבור הריפו ב-Workers Builds: Build command `npm run build`, Deploy command `npx wrangler deploy`.
(או מקומית: `npm run deploy`.)

אחרי הפריסה הראשונה:
1. להגדיר משתנה `EMDASH_SITE_URL` (Settings → Variables) לכתובת האתר.
2. לפתוח `https://<האתר>/_emdash/admin`, להשלים את אשף ההתקנה (כולל "טען תוכן לדוגמה") וליצור מנהל.
